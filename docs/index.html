Local AI MCP

One MCP server for every local model runtime. It knows what fits your GPU, and it never sends a prompt to the cloud unless you tell it to.

What it is

An operations-first control plane for the models on your own machine. Your agent can see what is installed and loaded across runtimes, check what will actually fit in your VRAM, get models ready, and hand work to the best local model with one delegate call. It runs over stdio only and never opens a network listener.

Local first, by construction

Each provider is local or hosted. Calls without a provider argument only use live local providers that have the model. Hosted APIs such as Moonshot are used only when named explicitly, or when you set LOCAL_AI_ALLOW_HOSTED_FALLBACK=1. Every result reports provider, host and local.

Hardware-aware

fit_check sizes the KV cache from the model's real layer architecture, sums VRAM across GPUs, models partial GPU/CPU offload and quantized KV caches, and understands Apple Silicon unified memory. Hardware probes cover NVIDIA, AMD (Linux sysfs, Windows registry), Intel, and Apple Silicon.

Install

Claude Code

claude mcp add local-ai -- npx -y @tmhs/local-ai-mcp

Claude Desktop: open the .mcpb bundle from the latest release. Any other client:

{ "mcpServers": { "local-ai": { "command": "npx", "args": ["-y", "@tmhs/local-ai-mcp"] } } }

Configuration is through environment variables; see the README and .env.example.
